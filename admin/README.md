# Vue3 管理后台（成员 4 负责）

> 负责人：成员 4（侯冠宇）
> 技术栈：Vue 3 + TypeScript + Vite
> 目录由成员 1 从仓库根目录迁移至此（2026-10-10）

---

## 说明

本目录存放管理后台前端工程，属于成员 4 的工作范围。

成员 1（后端架构）只负责：
- 提供后台所需的后端接口（`/api/v1/admin/*`，见 `docs/接口契约.md` 第九章）
- 定义后台接口的错误码（`1500~1599` 段）

成员 4 自行负责本目录的页面开发与假数据切换。

## 快速开始

```bash
cd admin
npm install
npm run dev
```

## 与后端对接

- 后端接口契约：`docs/接口契约.md` 第九章
- 后端服务地址：见 `docs/环境配置说明.md`
- 接口用假数据先行开发，后端就绪后切换真实接口
- 后台接口全部需要 `role = admin`，鉴权方式同 App（Bearer Token）
