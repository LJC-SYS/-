## 快速开始

```bash
cd backend
cp .env.example .env          # 修改 DATABASE_URL 和 JWT_SECRET_KEY
python -m venv .venv
./.venv/Scripts/python.exe -m pip install -r requirements.txt
./.venv/Scripts/python.exe -m alembic upgrade head
./.venv/Scripts/python.exe -m uvicorn app.main:app --reload
```

访问 http://127.0.0.1:8000/docs

详细步骤见 [backend/README.md](backend/README.md)。

## 开发约定（全员必读）

1. **接口以 [接口契约](docs/接口契约.md) 为准**。要改接口，先改文档、通知下游，再改代码。
2. **业务失败返回 HTTP 200 + 业务错误码**；401/403/422/500 只用于认证、权限、校验、异常。
3. **查询用户数据必须带 `user_id` 过滤**，防止越权。
4. **不提交 `.env`**，只提交 `.env.example`。
5. **改模型必须生成迁移脚本**，不允许手工改库结构。
6. 提交前跑一遍：

```bash
cd backend
./.venv/Scripts/python.exe scripts/smoke_test.py
```
